📦 Seolith Tiles v1.1.0
Release Notes & Novice Developer Engineering Guide

1. Why Normal JavaScript Slows Down at 1,500 Balls

Checking 1,600 balls against 4,096 micro-tiles is 6.5 million checks per frame! If built with normal DOM elements or naive JS loops, balls tunnel ("bleed") through thin walls and mobile browsers freeze.

2. Our 4-Pillar Solution (Rust + Three.js + WebAudio + Cloudflare)

  • 🦀 Rust WebAssembly Physics (src-rust/lib.rs): Runs at near-native speed. Uses O(1) spatial grid lookups and 16x sub-stepped Circle-vs-AABB closest-point math so balls never bleed through 1-tile-thick steel shafts.
  • 🎨 Three.js InstancedMesh (src/renderer.js): Draws all 6,400 tiles, 1,600 balls, and 1,200 shatter particles in just 4 GPU draw calls using Zero-Copy WebAssembly RAM views.
  • 🔊 Procedural WebAudio Synth (src/audio.js): Generates tactile ASMR woodblock pops & synthwave music mathematically with zero external MP3 downloads.
  • ☁️ Cloudflare Worker + D1 (worker/index.js): Powers Global/Country/Region leaderboards and our live Tester Feedback queue.
